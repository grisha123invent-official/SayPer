**Зажал клавишу, сказал, отпустил — текст появился там, где стоит курсор.**

Диктовка для macOS, живёт в строке меню. Записывает голос, отправляет в OpenAI Whisper
и вставляет расшифровку в то приложение, где ты печатал. Окна нет, в Dock не висит.

## Установка

Скачай из [релизов](https://github.com/grisha123invent-official/SayPer/releases).
Годится любой файл: `.dmg` красивее, `.zip` легче и блокируется на один раз меньше.

Приложение подписано, но **не заверено Apple** — для заверения нужно платное членство
в Developer Program. Поэтому macOS вешает на скачанный файл карантин и открывать его
отказывается. Обойти это можно двумя путями.

<img src="docs/install.jpg" alt="Окно установки" width="560">

### Одна команда, и дальше всё само

1. Открой **Терминал** (⌘Пробел, набери «Терминал»).
2. Набери вот это — **с пробелом в конце** — и пока не жми Enter:

   ```
   xattr -d com.apple.quarantine 
   ```

3. **Перетащи скачанный файл из Finder прямо в окно Терминала.** Полный путь подставится сам —
   неважно, где файл лежит и как называется. В этом весь смысл перетаскивания: если скачал дважды,
   вторая копия называется `SayPer-1.0 2.dmg`, и набирать такое руками — верный способ ошибиться.
4. Нажми **Enter**.

Теперь открывай образ, перетаскивай SayPer в «Программы» и запускай — ни одного предупреждения.
Снятый с образа карантин снимается и с приложения внутри, окно безопасности не появится вообще.

С архивом так же: сначала снять карантин, потом распаковать. Можно и наоборот — тогда команду
нужно направить на само приложение.

**Уже перетащил в «Программы» и получил блокировку?** Снимай карантин с приложения.
Ключ `-r` нужен потому, что приложение — это папка:

```bash
xattr -dr com.apple.quarantine /Applications/SayPer.app
```

**В ответ пришло «No such xattr»?** Значит карантина на файле и не было — просто открывай.

<details>
<summary><b>Без Терминала</b></summary>

<br>

1. Открой скачанный файл. macOS скажет, что не смогла его проверить, — нажми **Done**,
   а не «Move to Trash».
2. Зайди в **Системные настройки → Конфиденциальность и безопасность**, пролистай вниз.
   Там будет строка про заблокированный файл и кнопка **«Всё равно открыть»**. Нажми и подтверди.
3. Образ откроется. **Перетащи SayPer в «Программы»** — не запускай из образа или из «Загрузок»:
   оттуда macOS запускает копию из случайной папки только для чтения, и выданные разрешения
   не сохранятся.
4. Запусти приложение. **Оно заблокируется второй раз** — карантин переходит с образа
   на приложение. Повтори шаг 2 уже для него.

С архивом один круг отпадает: распаковал, перетащил в «Программы» — блокировка будет только одна,
на самом приложении.

Правый клик → «Открыть» больше не работает: Apple убрала этот обход в свежих версиях macOS.

</details>

## Первый запуск

Короткий помощник проводит по всему, что нужно:

- **Микрофон** — без него записывать нечего.
- **Универсальный доступ** и **Мониторинг ввода** — два разных разрешения, нужны оба. Первое даёт
  вставлять текст в чужие окна, второе — видеть горячую клавишу, пока работаешь в другом
  приложении. Сама себе macOS их выдать не позволяет, поэтому переключатели щёлкаешь ты, а помощник
  замечает это сразу. Ни перезапуска, ни кнопки «я сделал».
- **Ключ OpenAI** — заводится на [platform.openai.com](https://platform.openai.com/api-keys).
  Показывается один раз, копируй сразу.

## В работе

- **Esc** отменяет — и запись, и ожидание расшифровки, если ждать надоело.
- Не нравится держать клавишу? Переключись на **«нажал-нажал»**.
- Сочетание любое, включая голые модификаторы. Левые и правые клавиши различаются.
- Если сочетание из одних модификаторов, обычная клавиша во время записи её отменяет —
  привычные шорткаты продолжают работать.
- Два микрофона, два сочетания: одно пишет встроенным, другое гарнитурой. Что зажал —
  с того и пишется.

## Что ещё умеет

- **Ничего не теряется.** Запись лежит на диске, пока её текст не доставлен. Перезапустилось
  приложение посреди фразы — при следующем запуске оно подберёт запись само, дошифрует
  и положит в историю.
- **Видно, что происходит.** Каждая фраза в работе стоит в панели своей строкой:
  «расшифровываю», «связь подвела, повторяю (2 из 3)», «не дошло».
- **История** всего надиктованного, хранится локально. Любую строку можно скопировать
  или вставить заново.
- **Приглушение звука** на время записи, с возвратом прежней громкости.
- **Словарь** — имена и термины, которые Whisper иначе путает.
- **Причёсывание** — необязательный второй проход: знаки препинания и слова-паразиты.
- **Встроенный помощник** — спроси про приложение словами. Он знает и программу, и то, что
  настроено именно у тебя, а где дело решается настройкой — предложит кнопку. Нажимаешь ты,
  а не приложение.

## Приватность

- Звук уходит **в OpenAI** и больше никуда. Отправляется только на время расшифровки
  и на диске после доставки текста не остаётся.
- Ключ хранится на маке — в связке ключей, а если она недоступна локально подписанному
  приложению, в файле с правами `0600` в Application Support.
- История и расходы лежат локально, в `~/Library/Application Support/SayPer`.
- Ни телеметрии, ни аналитики, ни отчётов о падениях, ни своего сервера.

Если отправлять звук в OpenAI неприемлемо — `Transcriber` это один файл, его можно направить
на локальный `whisper.cpp`.

## Обновление

Автообновления пока нет. Новые версии выходят релизами здесь — скачать и заменить.

Разрешения переживают обновление: все сборки подписаны одним сертификатом.

## Сборка из исходников

Хватит Command Line Tools — ни Xcode, ни менеджера пакетов не нужно.

```bash
./build.sh          # собрать в dist/
./build.sh install  # собрать, поставить в /Applications и запустить
./build.sh dmg      # собрать образ
```

Устройство, подпись и разбор неполадок — в [docs/development.md](docs/development.md).

## Бери и переделывай

Приложение здесь целиком — без зависимостей и менеджера пакетов. Склонируй, запусти
`./build.sh install` — через минуту у тебя своя копия. Поменяй поведение горячей клавиши,
замени Whisper на локальную модель, перекрась окно: это твоё дело.

Пул-реквесты и issues приветствуются. Если лезешь в интерфейс — в [design/](design/) описаны
токены и состояния компонентов, из которых всё собрано.
