# Дизайн-система SayPer

Спецификация интерфейса: значения, из которых собран каждый экран, и правила,
по которым они применяются. Не история работы и не список задач — описание того,
как приложение устроено визуально, чтобы новый экран получился таким же, как
существующие.

| Файл | О чём |
|---|---|
| [tokens.md](tokens.md) | материалы стекла, цвета, отступы, радиусы, типографика, движение |
| [components.md](components.md) | каждый интерактивный элемент во всех состояниях |
| [ia.md](ia.md) | информационная архитектура: что где лежит и почему |
