# Спецификация компонентов

Значения — из `tokens.md`. Каждый интерактивный компонент описан во всех состояниях: покой, наведение, фокус, нажатие, выключен (плюс запись/ошибка там, где они есть). Состояние, для которого не написан стиль, считается несуществующим и всплывёт багом.

---

## 1. Переключатель (switch, а не чекбокс)

**Правило:** `.toggleStyle(.switch)` на каждом `Toggle` в окне. Чекбоксы в приложении не используются нигде.

**Анатомия строки**

```
┌──────────────────────────────────────────────────────┐
│ Показывать индикатор                          [ ●━ ] │  28pt
│ Пунктуация и слова-паразиты, +1 секунда              │  16pt, опционально
└──────────────────────────────────────────────────────┘
```

- Подпись слева, переключатель прижат вправо: `HStack { Text(...); Spacer(minLength: 12); Toggle("", isOn:).labelsHidden() }` — либо `LabeledContent`, что предпочтительнее: он сам держит выравнивание колонок между строками.
- Подпись — `.font(.body)`, `.primary`. Описание под ней — `.font(.subheadline)`, `.secondary`, максимум одна строка, `fixedSize(horizontal: false, vertical: true)`.
- Высота строки без описания — 28, с описанием — 44. Между строками — `spaceSm` (12).
- Ширина переключателя системная, `controlSize(.regular)`. Уменьшать до `.small` нельзя: это трогают пальцем по трекпаду, попадание важнее компактности.

**Состояния**

| Состояние | Оформление |
|---|---|
| Покой | Системное |
| Наведение | Системное (не переопределять) |
| Фокус | Системное кольцо, появляется мгновенно, без анимации |
| Нажатие | Системное |
| Выключен | `.disabled(true)`; подпись — `textTertiary`, вся строка `opacity 0.5`. Строка **не скрывается** |

**Нельзя:** делать анимацию перекрашивания подписи вслед за переключателем; использовать переключатель для выбора из двух равноправных вариантов (там сегменты — см. §6); прятать выключенные строки.

## 2. Поле записи хоткея

Основано на существующем `HotkeyRecorderView` (`HotkeyRecorder.swift`) — логика перехвата сохраняется, меняется отрисовка и добавляется сброс.

**Геометрия:** 190 × 28, `radiusField` (6), `cornerCurve = .continuous`. Внутри — `binding.displayString`, 13pt medium, по центру.

**Состояния**

| Состояние | Заливка | Обводка | Текст |
|---|---|---|---|
| Покой | `NSColor.controlBackgroundColor` | `NSColor.separatorColor`, 1pt | `.labelColor` |
| Наведение | `NSColor.controlBackgroundColor` + `surfaceRowHover` | `.separatorColor` | `.labelColor` + появляется иконка сброса справа |
| Фокус | как покой | системное фокусное кольцо, мгновенно | `.labelColor` |
| Запись | `controlAccentColor` alpha 0.12 | `controlAccentColor`, 2pt | `controlAccentColor`, 13pt **semibold**; текст = набранная часть сочетания или «Зажми сочетание…» |
| Ошибка ввода | `systemOrange` alpha 0.10 | `systemOrange`, 2pt | «Нужен хотя бы один модификатор», `systemOrange`, 11pt |
| Выключен | `controlBackgroundColor` alpha 0.5 | `.separatorColor` alpha 0.5 | `.tertiaryLabelColor` |

**Сброс.** Иконка `arrow.uturn.backward`, 12pt, `.secondaryLabelColor`, прижата к правому краю поля с отступом 6. Показывается при наведении на поле **и** при фокусе (не hover-only). Клик — возврат к `.rightOptionOnly`. Тултип: «Вернуть правый ⌥». Иконка не показывается, если текущее значение уже равно значению по умолчанию.

**Пульсации, мигания и анимированных обводок в режиме записи нет** — состояние читается по цвету и весу текста. Анимация здесь мешает целиться в клавиши.

**Оповещения о конфликте** остаются как есть: если сочетание невалидно (`isValid == false`), поле возвращается в покой без записи.

## 3. Карточка-секция

**Решение:** собственный контейнер, заголовок **внутри**, первой строкой.

```
┌─ radiusCard 12, surfaceCard, rimCard 1pt ─────────────┐
│ ↑ spaceMd 16                                          │
│ Горячая клавиша                    [опц. контрол]     │  13pt semibold
│ ↑ spaceSm 12                                          │
│ ─────────────────────────────────────────────────── │  hairline, инсет 12 слева
│ Зажимать                        [ ⌥ правый     ↺ ]    │  строка 28pt
│ ─────────────────────────────────────────────────── │
│ Кликни и зажми сочетание. Левые и правые различаются  │  11pt secondary
│ ↓ spaceMd 16                                          │
└───────────────────────────────────────────────────────┘
```

- Заливка `surfaceCard`, обводка `rimCard` 1pt, радиус 12 `.continuous`, **тени нет**, **блика нет** (карточка лежит, а не парит — П4).
- Внутренние поля 16 со всех сторон. Между карточками — `spaceXl` (24).
- Шапка: заголовок 13pt semibold слева, опциональный контрол справа (например сегменты периода в «Расходах»). Высота шапки 20.
- Разделители между строками — `hairline` с инсетом 12 слева, чтобы не резать карточку насквозь.
- Ширина — по контейнеру, максимум 640.

**Нельзя:** вкладывать карточку в карточку; давать карточке собственный `NSVisualEffectView` (второй слой размытия — П2); красить карточку акцентным цветом или добавлять цветную полосу слева.

## 4. Строка списка истории

**Анатомия (36pt, одна строка):**

```
┌─ radiusRow 8 ────────────────────────────────────────────────────┐
│ Привет, это тестовая расшифровка длинного текста…   14:32  ⧉  ⤓  │
└──────────────────────────────────────────────────────────────────┘
```

- Текст расшифровки: `.font(.body)`, `.primary`, одна строка, `.truncationMode(.tail)`, `lineLimit(1)`.
- Мета справа: время `14:32`, `.font(.subheadline)`, `.secondary`, `.monospacedDigit()`. При наведении время заменяется кнопками действий — ширина зоны фиксированная (56pt), чтобы текст не переливался.
- Кнопки: `doc.on.doc` (скопировать), `arrow.down.doc` (вставить снова), 14pt, `.secondaryLabelColor`, зона нажатия 24 × 24.
- Разделитель между строками — `hairline` с инсетом 12 слева.

**Состояния**

| Состояние | Оформление |
|---|---|
| Покой | Прозрачная, только текст и время |
| Наведение | `surfaceRowHover`, радиус 8; время → кнопки |
| Фокус (клавиатура) | Фокусное кольцо по контуру строки, кнопки видны |
| Выбрана | `surfaceRowSelected`, текст `.selectedMenuItemTextColor`-семантики |
| Скопировано | Время на 1.2 с заменяется на `checkmark` зелёным, затем возвращается. **Тоста нет** — молчаливый успех |

**Действия:** клик по строке — скопировать; ⌥+клик — вставить снова; двойной клик — раскрыть полный текст (строка растягивается до 3 строк, повторный двойной клик сворачивает). Контекстное меню правой кнопкой дублирует все три — это обязательное требование, иначе действия остаются hover-only.

**Развёрнутая строка:** высота по контенту до 3 строк (`lineLimit(3)`), затем тоже усечение. Полный текст целиком в списке не показывается никогда — для этого есть копирование.

## 5. Плитка статистики

**Анатомия (ряд из четырёх, `Grid`/`GridRow` или `HStack` с равными долями):**

```
┌─ radiusTile 10, surfaceTile ─┐
│ ↑ 12                         │
│ 128                          │  22pt semibold, monospacedDigit
│ минут                        │  11pt secondary
│ ↓ 12                         │
└──────────────────────────────┘
```

- Заливка `surfaceTile`, радиус 10 `.continuous`, **обводки нет** (плитка лежит внутри карточки, её граница читается по заливке), тени нет.
- Внутренние поля 12, между плитками `spaceSm` (12).
- Число: `.font(.system(size: 22, weight: .semibold).monospacedDigit())`, `.primary`. Моноширинные цифры обязательны — иначе значения в соседних плитках и в списке по дням не выстраиваются в колонку.
- Подпись: `.font(.subheadline)`, `.secondary`, нижний регистр, без двоеточий.
- Деньги: формат `$0.06`, два знака, `NumberFormatter` с `.currency` и локалью источника цены — не переводить в рубли и не округлять до целых, иначе мелкие суммы схлопнутся в `$0`.
- Единицы измерения не дублируются в числе: `128` + подпись `минут`, а не `128 мин`.

**Состояния:** плитка неинтерактивна — состояний наведения и фокуса нет, курсор не меняется. Если плитку когда-нибудь сделают кликабельной, она получит `surfaceRowHover` при наведении и фокусное кольцо; до тех пор — никакого `cursor: pointer`-эквивалента.

**Пустые данные:** вместо нуля — `—` в `.tertiaryLabelColor`. Выдуманных значений в плитках не бывает.

## 6. Полоса разделов (стеклянная капсула)

Нужна для навигационной модели из `ia.md`; это единственная поверхность, которая берёт блик из референса 3.

- Контейнер: `NSVisualEffectView` `.headerView` + `.withinWindow`, скруглён в капсулу (`radiusCapsule`), обводка `rimGlass` 1pt, градиент `specular` по верхней кромке.
- Высота капсулы 32, высота аксессуара в титлбаре 44 (по 6 сверху и снизу).
- Сегмент: иконка 15pt + подпись 11pt, `spacing 6`, горизонтальные поля 12, минимальная ширина 84.
- Активный сегмент: заливка `surfaceTabActive`, радиус капсулы, текст и иконка `.primary`, вес подписи `.medium`.
- Неактивный: без заливки, `.secondary`.
- Наведение на неактивный: заливка `surfaceRowHover`, переход `durHover` (0.12) по прозрачности.
- Фокус: кольцо по контуру сегмента, мгновенно; переключение стрелками ←→.
- Клавиши: ⌘1…⌘5 переключают разделы.
- Смена раздела — **без анимации перехода контента**.

## 7. Кнопка-капсула

Единый вид для действий в карточках и в баннере доступа.

- Высота 26, горизонтальные поля 14, радиус `height/2` `.continuous`, `.font(.body)`.
- **Обычная:** заливка `surfaceTile`, обводка `rimCard`, текст `.primary`.
- **Основная** (одна на экран, П6): заливка `controlAccentColor`, текст `.white`, обводки нет.
- Наведение: заливка на один уровень плотнее, `durHover`. Никакого `scale`.
- Нажатие: заливка ещё на уровень плотнее, без сдвига.
- Загрузка: текст остаётся, слева появляется `ProgressView().controlSize(.small)`, кнопка `.disabled(true)`. Спиннер показывается с задержкой 150 мс и держится минимум 300 мс — иначе он мигает на быстрых ответах.
- Выключена: `opacity 0.5`, курсор не меняется.
- Результат действия — иконка + текст рядом с кнопкой (как сейчас у «Проверить ключ»), не всплывающий тост.
