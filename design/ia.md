# Информационная архитектура

Две поверхности: окно настроек и меню в строке статуса. Принцип раскладки один — **частота обращения**. Приложением пользуются каждый день по несколько секунд; то, что трогают ежедневно, лежит в меню, то, что настраивают раз в неделю, — в первом разделе окна, то, что настраивают один раз, — в последнем.

---

## 1. Навигационная модель окна настроек: вкладки, не боковой список

**Решение: горизонтальная полоса разделов (вкладки) под титлбаром.**

Обоснование по трём осям:

- **Число разделов — 5, иерархии нет.** Боковой список окупается от 7+ пунктов или при вложенности (как в Системных настройках, где разделов больше двадцати). На пяти плоских пунктах он выглядит полупустым.
- **Цена по площади.** Боковой список забирает ~190pt по горизонтали **постоянно**, на всех разделах. Полоса вкладок забирает 44pt по вертикали один раз, и окно остаётся узким (740pt), а разделы «История» и «Расходы» получают всю ширину под таблицу и плитки.
- **Скорость доступа.** Клик в раздел — один и там, и там, но вкладки дают ⌘1…⌘5 и не требуют перевода взгляда с левого края на правый. Для утилиты, которую открывают на 10 секунд, это решающий аргумент.

Дополнительно: вкладки — это ровно референс 3 (стеклянная капсула с иконкой и подписью), то есть навигация несёт ДНК, а не спорит с ней.

**Реализация:** `NSTitlebarAccessoryViewController` с `layoutAttribute = .bottom`, внутри — кастомная стеклянная капсула-сегментированный контрол (спека в `components.md`). Переключение раздела — без анимации перехода.

### Разделы

| # | Раздел | Symbol | Что внутри | Частота |
|---|---|---|---|---|
| 1 | **Запись** | `mic` | Горячая клавиша · Режим (удержание / нажал-нажал) · Показывать индикатор · Звуковые сигналы | Настраивают в первую неделю, потом редко |
| 2 | **Текст** | `text.alignleft` | Модель · Язык речи · Причёсывать текст · Словарь · Способ вставки | Правят по мере накопления опыта |
| 3 | **История** | `clock.arrow.circlepath` | Последние ~20 расшифровок: посмотреть, скопировать, вставить повторно | Ежедневно |
| 4 | **Расходы** | `chart.bar` | Минуты, слова, потраченные доллары — по дням и за месяц | Раз в неделю |
| 5 | **Ключ и доступ** | `key` | API-ключ + проверка · Доступ к клавиатуре · Запускать при входе | Один раз при установке |

Порядок — по убыванию частоты настройки, «поставил и забыл» уходит в конец. Раздел по умолчанию — **Запись**, кроме двух случаев:
- ключа нет → открывается **Ключ и доступ**;
- нет доступа к клавиатуре → открывается **Ключ и доступ**, вверху — баннер (см. §1.4).

### 1.1 Раздел «Запись»

Карточка **«Горячая клавиша»**
- Строка: `Зажимать` + поле записи хоткея (в поле — иконка сброса при наведении, вместо ссылки «Сбросить на правый ⌥»).
- Одна подсказка, 11pt, серым, под полем.

Карточка **«Режим»**
- Сегментированный контрол на две позиции: `Удержание` / `Нажал-нажал`. Именно сегменты, а не переключатель: это выбор из двух равноправных вариантов, а не включение опции.
- Под ним — одна строка описания, меняющаяся вместе с выбором: для удержания «Держи клавишу и говори, отпустил — расшифровка», для нажал-нажал «Нажал — говоришь, нажал ещё раз — расшифровка».

Карточка **«Во время записи»**
- Переключатель `Показывать индикатор`
- Переключатель `Звуковые сигналы`

### 1.2 Раздел «Текст»

Карточка **«Расшифровка»**
- `Модель` (Picker)
- `Язык речи` (Picker)
- Переключатель `Причёсывать текст` + описание под ним одной строкой.

Карточка **«Словарь»**
- Редактор на 3 строки, плейсхолдер вместо отдельной подписи-заголовка.

Карточка **«Вставка»**
- `Способ` (Picker)

### 1.3 Раздел «История»

- Список последних 20 записей, одна расшифровка — одна строка (спека строки в `components.md`).
- Над списком — поле поиска, если записей больше 10; иначе поля нет.
- Действия по строке: клик — скопировать, ⌥+клик или кнопка — вставить повторно в активное поле. Кнопки появляются при наведении, но **дублируются в контекстном меню строки** — hover-only-афорданс запрещён.
- Пустое состояние: одна строка «Здесь появятся последние расшифровки» + иконка. Без иллюстраций.
- Внизу — `Очистить историю`, отбитая на 32pt от списка, обычной кнопкой (не destructive-красной: действие обратимо в пределах сессии не будет, но и не катастрофично; красной делать нельзя, чтобы не создавать второе контрастное пятно, П6).

### 1.4 Раздел «Расходы»

- Ряд из четырёх плиток статистики за текущий месяц: `Минуты`, `Слова`, `Расшифровок`, `Потрачено`. Числа — моноширинные.
- Под ними — список по дням: дата, минуты, доллары. Правая колонка выровнена по разряду.
- Заголовок над списком с переключением периода: `Этот месяц` / `Прошлый месяц` — сегментами.
- Одна строка мелким серым: как считается стоимость (по тарифу выбранной модели). Больше пояснений не давать.

### 1.5 Раздел «Ключ и доступ»

Карточка **«OpenAI»**
- Поле ключа + иконка вставки из буфера внутри поля справа (кнопка «Вставить» текстом исчезает).
- Кнопка `Проверить ключ` + результат справа от неё иконкой и текстом.
- Одна подсказка: «Ключ хранится в связке ключей macOS».

Карточка **«Доступ к клавиатуре»**
- Строка статуса: SF Symbol + текст.
- Кнопка `Открыть настройки доступа` (и `Проверить` — только когда доступа нет).

Карточка **«Система»**
- Переключатель `Запускать при входе в систему`.

**Баннер отсутствия доступа.** Когда доступа к клавиатуре нет, вверху **любого** раздела показывается полоса: `exclamationmark.triangle.fill` + «Нет доступа к клавиатуре — хоткей не сработает» + кнопка-капсула `Выдать доступ`. Это единственный элемент, который имеет право быть выше карточек: без него приложение не работает вообще.

## 2. Что убрать с глаз

| Что | Куда | Почему |
|---|---|---|
| «Диагностика…» | Меню, альтернативный пункт под ⌥ (`isAlternate` у «Настройки…») | Нужна раз в жизни, при разборе поломки |
| Ссылка «Сбросить на правый ⌥» | Иконка `arrow.uturn.backward` внутри поля хоткея, появляется при наведении и по фокусу | Отдельная строка ради редкого действия |
| Кнопка «Вставить» рядом с полем ключа | Иконка внутри поля справа | ⌘V работает; кнопка нужна как запасной путь, но не как равноправный элемент |
| Кнопка «Проверить» рядом с доступом | Показывать только когда доступа нет | При выданном доступе нечего проверять |
| Текст ошибки автозапуска | Под переключателем, только когда ошибка есть | Уже так; сохранить |
| Длинная простыня в алерте «Нужен доступ к клавиатуре» (`AppDelegate.swift:249-260`) | Сократить до трёх строк: что не работает, куда идти, что удаление и повторное добавление лечит зависший случай | Шесть абзацев в модальном окне никто не читает |

## 3. Подсказки: было 6, стало 2

Сейчас в окне шесть блоков серого текста; пять из них объясняют то, что видно из самого контрола.

| Подсказка (сейчас) | Решение |
|---|---|
| «Ключ хранится в связке ключей macOS, а не в файле настроек.» | **Оставить**, сократив до «Ключ хранится в связке ключей macOS». Это неочевидный факт про безопасность |
| «Кликни по полю и зажми любое сочетание — хоть один модификатор, хоть ⌃⌥D. Левые и правые клавиши различаются.» | **Сократить** до «Кликни и зажми сочетание. Левые и правые клавиши различаются». Остальное поле показывает само |
| «Держи и говори. Нажатая во время удержания обычная клавиша отменяет запись…» (и её вторая ветка) | **Перенести** в описание под сегментами «Режим» — там это ответ на вопрос «чем режимы отличаются», а не подсказка про поле |
| «Esc прерывает и запись, и ожидание расшифровки.» | **Убрать из окна**, показать в HUD-индикаторе при записи дольше 3 секунд подписью «Esc — отмена» | 
| «Расставит пунктуацию и уберёт слова-паразиты. Добавляет ~1 секунду.» | **Сократить** до «Пунктуация и слова-паразиты, +1 секунда» — оставить как описание под переключателем |
| «Словарь: имена и термины через запятую» | **Убрать как подпись**, перенести в плейсхолдер редактора |

Правило на будущее: подсказка допустима, только если объясняет **последствие**, невидимое из контрола (где лежит ключ, сколько это стоит по времени). Подсказка, пересказывающая название контрола, удаляется.

## 4. Меню в строке статуса

Меню — не оглавление приложения, а место для двух вещей: понять состояние и достать последний текст. Всё остальное — вглубь.

### Порядок пунктов

```
[!] Нет доступа к клавиатуре            ← только когда доступа нет
─────────────────────────────
Готово · зажми ⌥                        ← строка состояния, disabled
─────────────────────────────
Скопировать «превью последнего текста…»  ⌘C
Вставить снова                           ← только когда есть последний текст
История                                ▸
─────────────────────────────
Сегодня: 4 мин · $0.06                   ← открывает раздел «Расходы»
Режим                                  ▸
─────────────────────────────
Настройки…                              ⌘,
  ⌥ Диагностика…                        ← альтернативный пункт, виден по ⌥
─────────────────────────────
Выйти                                   ⌘Q
```

### Что показывается динамически

| Элемент | Логика |
|---|---|
| Иконка в строке статуса | `mic` покой · `mic.fill` запись · `waveform` расшифровка · `exclamationmark.triangle` ошибка. Template-изображение, чтобы следовать теме строки меню |
| Первая строка (доступ) | Только при `!hotkeys.isActive`. Иконка `exclamationmark.triangle.fill` оранжевым, действие — текущий `requestKeyboardAccess` |
| Строка состояния | `Готово · зажми ⌥` / `Идёт запись…` / `Расшифровка… 3 с` / `Ошибка: …`. Секунды в расшифровке — те же, что в HUD |
| «Скопировать…» | Только при наличии последнего текста; в заголовке — превью до 40 символов (сейчас 60 — при системном шрифте меню это уже слишком широкое меню) |
| «Вставить снова» | Только при наличии последнего текста |
| «История» ▸ | Подменю: 5 последних записей (превью 40 символов + время справа), затем разделитель, затем `Показать все…` → открывает окно на разделе «История». Скрыто целиком, когда история пуста |
| «Сегодня: N мин · $X.XX» | Активный пункт, открывает окно на разделе «Расходы». Скрыт, если за сегодня записей нет |
| «Режим» ▸ | Подменю из двух пунктов-радио: `Удержание` / `Нажал-нажал`, галочка на активном. Это единственная настройка в меню — она меняет способ работы прямо сейчас, остальные так не работают |
| «Диагностика…» | `isAlternate = true` у пункта «Настройки…», `keyEquivalentModifierMask = .option` |

### Что в меню не попадает

Модель, язык, словарь, звуки, индикатор, автозапуск, API-ключ. Всё это меняется в окне: они не помогают принять решение в момент, когда меню открыто.

**Правило порядка:** сверху — то, что блокирует работу (доступ) и описывает текущее состояние; в середине — действия с результатом; ниже — цифры и режим; внизу — вход в настройки и выход. Разделители отбивают эти четыре смысловые группы, а не отдельные пункты.
